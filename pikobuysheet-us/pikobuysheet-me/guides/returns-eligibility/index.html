PikoBuy Returns Eligibility

Return questions should be reviewed as soon as an item reaches the warehouse. Eligibility, timing, seller consent and cost responsibility are separate issues.

Check the current conditions

Start with the original seller’s return status and the product’s condition. A seller may require the item to remain resalable, with labels, seals, packaging and accessories intact. Some categories can have special conditions or exclusions.

Act before international shipping

Keep the warehouse status, photos and order record together. If a visible mismatch appears, submit the truthful reason through the available order process before the relevant warehouse deadline. A request is not the same as approval, and seller consent may still be required.

Do not assume costs or outcomes

Return shipping or service fees can depend on the reason and the applicable policy. A product leaving the warehouse in an international parcel can make a return more complex, so resolve seller-related questions first where possible.
