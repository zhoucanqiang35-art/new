# Sheet LitBuy project memory

- Domain: `sheet-litbuy.com`; intended GitHub folder: `sheet-litbuy-com/`.
- This is an independent LitBuy discovery interface. Product records, product images, search, image-search, QC media, categories and sorting must be requested from `https://findspreadsheet.com`; never seed or persist a separate catalogue.
- The public check preview reads directly from FindSpreadsheet during the preview build and does not include a local product export or task/demo product images.
- Official LitBuy logo and favicon must be loaded from LitBuy official-origin URLs.
- Confirmed official outbound links: Register `https://litbuy.com/register`; purchase `https://litbuy.com/product/weidian/{productId}`.
- Default language is English. Future locales must switch every interface and authored SEO string together while keeping source product data unchanged.
