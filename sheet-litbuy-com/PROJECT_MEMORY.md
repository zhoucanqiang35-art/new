# Sheet LitBuy project memory

- Domain: `sheet-litbuy.com`; GitHub folder: `sheet-litbuy-com/`.
- This is an independent LitBuy discovery interface. Product records, product images, search, image-search, QC media, categories and sorting must be requested from `https://findspreadsheet.com`; never seed or persist a separate catalogue.
- The public check preview is a static build that retrieves the current FindSpreadsheet listing and source-gallery URLs at build time; it displays an honest unavailable state if the upstream source cannot be reached. Production deployment may move this same source adapter to Astro SSR.
- USD is the default visible price. It is an indicative conversion of the upstream CNY price at a documented rate; original CNY remains visible and checkout is the source of truth.
- Product cards use FindSpreadsheet-origin WebP transform URLs with `srcset`/`sizes`. Extra source-gallery (QC where upstream provides it) images have no `img src` until the visitor expands the card.
- The visual-search UI may accept a local reference preview and promo links may match an existing Weidian/source ID. Do not claim reverse-image results until FindSpreadsheet exposes a real visual-search endpoint.
