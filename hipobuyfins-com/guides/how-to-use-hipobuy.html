How to use a HipoBuy spreadsheet

This is an independent research and discovery website. It is not an official Hipobuy website and does not sell or process products.

Find

Start with the category or a specific search and open the current listing. Record the item, seller, price, size and colour; a spreadsheet entry is a starting point, not proof that the option is still available.

Check

Compare the selected option with the size chart and seller images before placing an order. The item price can exclude domestic delivery, international shipping, payment charges and import costs. Check the current checkout rather than adding an assumed flat fee.

Decide

After warehouse arrival, review the available QC pictures and ask about discrepancies before approving shipment. Group only items you intend to keep, compare the available parcel routes and confirm the final charge and restrictions in the live order flow.
