Product detail method

One item, one clear reason to keep it.

Before opening the live database, record the product type, source clue, photos, size information, listed price and package implications. This creates a shortlist that is easier to revisit.

Five-minute comparison method

  1. Check that the source page, options and photos still match the spreadsheet row.
  2. Compare similar products in the same category rather than isolated titles.
  3. Check size or dimensions before judging price.
  4. Identify what needs QC confirmation at warehouse stage.
  5. Consider whether the expected package effect changes the value.
